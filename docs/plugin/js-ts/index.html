JS 与 TypeScript 插件

Node 类型剥离、脚本约定

JS 与 Python 走的是同一份 Rust 桥（fuyubot-sdk-script），也共用同一套「一行一个 JSON」协议， 差别只在解释器和你写脚本的语言。TypeScript 不需要 tsc：宿主起的是 node demo.ts， 靠 Node 自带的类型剥离直接跑。

object() / text() 是示例里的两个窄化小函数（JS 侧没有 schema，取字段前先窄化成对象）。 sendMessage 的参数形状以 TDLib 为准，见 调用 TDLib。

类型剥离只认能剥掉的语法：注解、interface / type、as。 不能用 enum / namespace / 构造器参数属性——那些需要真正的编译。 Node 要 ≥ 23.6（默认开）；22.6+ 得加 --experimental-strip-types。你本机的 Node 太老就自己 tsc 编成 .js：编译与打包是作者自己的工具链。

脚本约定（与 Python 完全一致）

约定说明
同名同目录counter.dll ↔ counter.js（或 .ts）；宿主依次试 .py / .js / .ts
run() 最后一行宿主收到 {"op":"ready"} 才算加载完成，plugin_start 等它（上限 10 秒）
UTF-8桥把 stdio 钉成 UTF-8；脚本自己的输出一律按 UTF-8 走
起不来就失败解释器缺失、脚本语法错都会让 plugin_start 返回错误，不会静默变成空插件

解释器依次试 node / bun。[lib] name 必须与脚本同名，否则默认的 fuyubot_example_counter.dll 找不到 counter.ts。
