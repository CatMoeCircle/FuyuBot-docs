插件迁移指南

将旧插件迁移到 package.json 清单 + 依赖加载 + plugin-api 类型包的新格式

插件迁移指南

FuyuBot 插件系统已支持：

  • 包插件：复用 package.json 的 name/version/description，用 pluginType / pluginDependencies 声明插件专有字段；
  • 类型包：通过 @fuyu-tdbot/plugin-api 导入 Plugin、PluginAPI 等完整类型；
  • 依赖加载：按 pluginDependencies 拓扑排序，依赖先加载；
  • 禁用预过滤：读取包名阶段即排除已禁用插件，不执行 import；
  • 单文件兼容：顶层 .ts 插件保持原样，最后加载。

本页说明如何从旧格式迁到新格式。

两种插件形态

形态位置元数据契约导入加载顺序
单文件插件plugins/*.ts类字段 name / type / …亦建议 @fuyu-tdbot/plugin-api最后加载
包插件（推荐）plugins/<dir>/package.json 的 pluginType@fuyu-tdbot/plugin-api先加载，可声明依赖

迁移范围

目录插件建议迁到包插件格式。单文件插件可继续使用类字段，无需强制迁移。

何时需要迁移

出现以下情况时，建议迁移：

  • 插件是多文件目录，希望元数据与依赖可被框架在 import 之前读取；
  • 需要声明「先加载另一个插件」的依赖关系；
  • 希望在独立仓库 / 独立 IDE 窗口中开发，仍能解析 Plugin / PluginAPI 等类型；
  • 需要在禁用时完全不加载模块，避免占用内存。

迁移步骤（目录插件）

1. 补齐 / 修改 package.json

在插件目录根添加（或更新）package.json：

package.json 插件字段说明

字段必填说明
name是运行时插件 id：禁用列表、依赖声明、注册表键都用它
pluginType是"user" | "bot" | "general"
version是版本号
description是简短描述（可为空字符串，但不能缺字段）
pluginDependencies否其他插件的 name 数组，依赖会先加载

name 必须稳定

禁用配置里写的是 package.json 的 name（例如 adblock）。改 name 会打断已有禁用列表与依赖声明。

依赖其他插件

  • 框架会按拓扑顺序加载：依赖在前；
  • 依赖缺失或被禁用时会告警，插件仍尝试加载；
  • 循环依赖会告警并跳过环上重复访问。

加载时：

  1. 先加载全部包插件（按依赖拓扑）；

  3. 最后加载顶层单文件插件。

禁用插件

在配置的 plugins.disabled 数组中写入 name（package.json）（或单文件类字段的 name）：

  • 包插件：扫描读到清单名后即跳过，不会 import，减少内存占用；
  • 单文件插件：仍会在导入并实例化后根据 name 跳过注册（无法在读文件名时知道显示名）。

检查清单

迁移完成后自检：

  • package.json 含 name / version / description / pluginType
  • pluginDependencies 使用的是其他插件的 name
  • 入口 import { Plugin } from "@fuyu-tdbot/plugin-api"
  • 类中没有重复的 name / version / description / pluginType
  • 框架根目录已 pnpm install
  • 启动日志中插件元数据正确
  • （可选）独立打开插件目录，tsc 能解析 @fuyu-tdbot/plugin-api

仍依赖框架路径别名的部分

@fuyu-tdbot/plugin-api 解决的是插件契约类型。以下别名仍由框架根 tsconfig / loader 提供，插件在框架仓库内运行时可继续使用：

别名用途
@log/*日志
@TDLib/*TDLib 封装
@db/*配置 / 数据库
@function/*通用函数
@utils/*工具
@plugin/*框架内部插件工具（如 inlineTools）

将插件整包拷出仓库独立运行前，还需要框架提供对应的宿主 SDK 包；当前契约层（plugin-api）已按仓库外格式设计。

常见问题

迁移后插件名变了 / 禁用失效？
检查禁用列表是否仍使用旧 name；新 id 以 name（package.json） 为准。

报缺少 @fuyu-tdbot/plugin-api？
在框架根执行 pnpm install，确认插件 dependencies 中有 "@fuyu-tdbot/plugin-api": "workspace:*"。

依赖插件没先加载？
确认依赖方的 name（package.json） 拼写完全一致，且依赖未被禁用。

单文件还需要改成 package.json 吗？
不需要。单文件继续用类字段即可；只有目录 / 多文件插件推荐包格式。
