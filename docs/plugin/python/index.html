Python 插件

用薄 SDK 写 Python 脚本插件：一个目录就是插件，不编译、不碰 ABI

Python 插件就是一个目录：manifest（pyproject.toml）里写身份，main.py 写逻辑， fuyubot.py（单文件薄 SDK）负责和宿主通信。三步上手见 脚本插件，本页是 API 参考。

manifest：pyproject.toml

API

fuyubot.py 随 FuyuBot-SDK 提供 （crates/fuyubot-sdk-native/ 下），拷进插件目录即可 from fuyubot import …。 它只是原生桥的一层 ctypes 封装，协议细节（握手、订阅号、JSON 管道）作者看不见。

函数签名说明
onon(event, handler, filter=None)订阅事件。是两参数函数，不是装饰器；同一个事件可订阅多次
invokeinvoke(method, params=None, on_response=None)发 TDLib 请求；给了 on_response 就按 request_id 自动配对
emitemit(event, payload=None)发自定义事件（只送自己 + 全局订阅者，不是广播）
loglog(message, level="info")level：error / warn / info / debug / trace
register_toolregister_tool(name, description="", input_schema=None)只登记元数据
use_middlewareuse_middleware(stage, handler)挂中间件，handler(stage, payload)
runrun()握手并开始收事件。永远放最后一行

on 的 filter 是点分路径的字段相等匹配，比如只听 /hello：

  • payload 是解析好的 dict，直接取字段；不用自己拼 JSON。
  • invoke 的参数形状以 TDLib 为准（方法名 ≠ Bot API），见 调用 TDLib。
  • run() 必须是最后一行：它发就绪握手并阻塞收事件，脚本提前退出 = 插件加载失败。

原生桥

薄 SDK 要加载原生桥（和托管插件是同一份库）。查找顺序：脚本同目录 → 环境变量 FUYUBOT_NATIVE_LIB → 当前工作目录；找不到会报「找不到 fuyubot 原生桥库」， 排法见 脚本插件的常见问题。

调试

  • 日志不够细就把 [plugins].log_level 调成 "debug"（见配置文件）。
  • Python 侧要装 uv（机器人用 uv sync 装依赖、uv run 起脚本）； 缺了的话脚本起不来，日志里有提示，不影响机器人本身。
