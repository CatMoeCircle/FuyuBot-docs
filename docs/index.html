fuyubot 文档

基于 TDLib 的 Telegram bot / user 框架

fuyubot 是一个基于 TDLib 的 Telegram bot / user 框架：Rust 内核 + C ABI 插件 + 多语言 SDK。 插件就是一个动态库（.dll / .so / .dylib），一个 cdylib 就是一个插件。

CLI 文档

fuyubot 与 fuyubot-sdk 的完整命令参考

两个 CLI，职责严格分离

CLI干什么子命令
fuyubot跑框架init / run / status / stop / plugin
fuyubot-sdk写插件init / codegen / check / abi-version / td-methods / td-method

两个都不编译、不打包插件——编译是插件作者用自己语言工具链（cargo build、cl /LD、gcc -shared）完成的事， fuyubot plugin install 只负责把编好的产物复制进插件目录。

现在能验证到什么程度

离线回放（--replay）与实例三件套（单实例锁 / 后台运行 / status / stop）是端到端跑过的。 真实账号登录 run 会接上 TDLib 走授权状态机，但没有拿真账号端到端验过「收真更新 → 插件回一条」。

  • 内核、插件 ABI、加载器、更新管线、四大机制：有测试，全绿
  • 真 TDLib（真 tdjson + 真 td_api.tl）：getMe 往返、同步 execute、插件调 TDLib 收响应，都在 -- --ignored 自检里验过
  • td_api.tl 在编译期被转成元数据烤进二进制，运行时不读文件、不解析
  • tdjson 运行时动态加载，构建期会把它拷到可执行文件同级目录
