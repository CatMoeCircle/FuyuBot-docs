下载与安装

下载对应平台的包，解压就能跑

不用装 Rust、不用编译：到 Releases 下对应平台的 zip， 解压后里面就是可执行文件，TDLib 动态库已经和它放在同一个目录（运行时按「可执行文件所在目录」 自动找到，不用配环境变量、不用单独装 TDLib），内置插件在同级的 plugins/。

下载哪个包

资产名是 fuyubot-<版本>-<OS>-<平台>.zip（例：fuyubot-v0.1.0-windows-x86_64.zip）： <版本> 就是 Release 版本号，带在名字里方便一眼看出下的是哪个；<OS> = windows / linux / macos， <平台> = x86_64 / aarch64（cargo 口径，和 TDLib 自己的资产同序）。

系统资产包里有什么
Windows 10/11（x64）fuyubot-<版本>-windows-x86_64.zipfuyubot.exe + tdjson.dll + plugins/ + README.txt
Windows 11（ARM64）fuyubot-<版本>-windows-aarch64.zipfuyubot.exe + tdjson.dll + plugins/ + README.txt
Linux（x86_64）fuyubot-<版本>-linux-x86_64.zipfuyubot + libtdjson.so + plugins/ + README.txt
Linux（ARM64）fuyubot-<版本>-linux-aarch64.zipfuyubot + libtdjson.so + plugins/ + README.txt
macOS（Apple Silicon）fuyubot-<版本>-macos-aarch64.zipfuyubot + libtdjson.dylib + plugins/ + README.txt
  • 解压出来就是本体：zip 里没有额外的一层目录，建议先建一个空目录再往里解压。
  • 归档一律 .zip（Windows 资源管理器双击就能解，Linux / macOS 用 unzip）。
  • 上面没有的平台（Intel Mac 等）暂时没有包，自己编：见 从源码构建。
  • 插件开发 CLI（fuyubot-sdk）在另一个仓库的 Release 里： FuyuBot-SDK 的 fuyubot-sdk-<系统>-<架构>.zip， 它不需要 tdjson。
