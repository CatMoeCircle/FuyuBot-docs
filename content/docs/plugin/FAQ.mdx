## 插件常见问答（FAQ）

- **问：插件没有被加载，应该如何排查？**
	- 答：确认插件目录或文件名不以 `.` 开头，且不在 `node_modules` 目录下。包插件检查 `package.json` 是否含 `name`/`version`/`description`/`pluginType`，入口 `main` 或 `index.ts` 是否存在。检查是否在 `plugins.disabled` 中（包插件会在读名单阶段直接跳过）。确保根目录已 `pnpm install`。

- **问：报错“缺少默认导出”，如何修复？**
	- 答：确保你的模块使用 `export default` 导出插件类，且继承自 `Plugin`。包插件从契约包导入：

	```ts
    import { Plugin } from "@fuyu-tdbot/plugin-api";
	export default class MyPlugin extends Plugin {
		// ...实现...
	}
	```

	单文件插件也可用：

	```ts
    import { Plugin } from "@fuyu-tdbot/plugin-api";
	export default class MyPlugin extends Plugin {}
	```

- **问：包插件和单文件插件有什么区别？**
	- 答：包插件是带 `pluginType` 的目录，元数据在 `package.json`，可声明 `pluginDependencies` 做加载排序，并在禁用时不 import；单文件是顶层 `.ts`，元数据在类字段，**最后加载**。迁移步骤见[插件迁移指南](/docs/plugin/Migration)。

- **问：禁用插件应该填哪个名字？**
	- 答：填 `package.json` 的 `name`（包插件）或类字段 `name`（单文件）。例如 `"adblock"`、`"fuyu-plugins"`。

- **问：如何让插件 A 在插件 B 之后加载？**
	- 答：在 A 的 `pluginDependencies` 里写上 B 的 `name`，例如 `"pluginDependencies": ["puppeteer"]`。框架会按拓扑顺序先加载依赖。

- **问：发送消息后返回消息对象中的id不能用**
	- 答：发送消息后返回的是正在发送中的消息对象,发送成功的你需要监听 `updateMessageSendSucceeded` 更新，该事件会包含正式的消息 ID 和旧消息 ID 和最终状态；不要仅依赖发送中的消息值作为最终消息。
    - 因此我们封装了一个 `sendMessage` 的函数，来帮助你发送消息并等待发送成功的结果, 这个方法精简了调用流程并直接返回最终的消息对象，优化了原版中发送消息的复杂程度,支持参数你可以在 `src\TDLib\types\message.d.ts` 中 `sendMessage` 找到。示例用法如下： 
    ```ts
    import { sendMessage } from "@TDLib/function/message.ts";

    const result = await sendMessage(client, chatId, {
      text: "hello world",
    });
    ```

- **问：调用 TDLib 原生方法失败，去哪查文档？**
	- 答：参考官方 TDLib 方法文档： https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1_function.html ，确认传参、类型与调用方式符合 TDLib 要求。
    ```ts
    const result = await client.invoke({
      _: "sendMessage",
      chat_id: chatId,
      input_message_content: {
        _: "inputMessageText",
        text: {
          _: "formattedText",
          text: "hello world",
        },
      },
    });
    ```

- **问：找不到 `@fuyu-tdbot/plugin-api`？**
	- 答：在框架根目录执行 `pnpm install`，并确认插件 `package.json` 的 `dependencies` 含 `"@fuyu-tdbot/plugin-api": "workspace:*"`。独立仓库开发时改用 `file:` / `link:` / 发布版本号。

- **问：我想看更多示例或扩展插件框架，有建议吗？**
	- 答： 示例中有若干示例，阅读这些示例可以快速上手；如有功能建议或补充示例，欢迎在 [文档仓库](https://github.com/CatMoeCircle/FuyuBot-docs) 提交 PR 和 [主仓库](https://github.com/CatMoeCircle/Fuyu_TDBot) 提交 issue，我们会持续完善文档和示例库。
