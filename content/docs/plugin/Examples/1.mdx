### 快速开始（包插件 · 推荐）

目录插件在 `package.json` 中声明元数据与依赖，入口从 `@fuyu-tdbot/plugin-api` 导入契约：

```json title="plugins/my-plugin/package.json"
{
  "name": "my-plugin",
  "version": "1.0.0",
  "description": "插件简短描述",
  "main": "index.ts",
  "type": "module",
  "pluginType": "general",
  "dependencies": {
    "@fuyu-tdbot/plugin-api": "workspace:*"
  }
}
```

```ts title="plugins/my-plugin/index.ts"
import { Plugin } from "@fuyu-tdbot/plugin-api";
import type { Client } from "tdl";

export default class LifePlugin extends Plugin {
  // name/version/description/pluginType 由 package.json 注入，类中勿重复声明
  constructor(client: Client) {
    super(client);
    this.cmdHandlers = {
      // 命令注册名称
      hello: {
        description: "问候用户", // 命令的简短描述
        scope: "private", // 命令的运行环境 "all" | "private" | "group" | "channel" 可数组表示多个环境
        permission: "owner", // 命令的调用权限 "owner" | "admin" | "all"
        showInHelp: true,
        handler: async (updateNewMessage, _args) => {
          console.log(updateNewMessage);
        },
      },
    };
  }
}
```

在框架根目录执行 `pnpm install` 后启动即可加载。需要依赖其他插件时，把对方的 `name` 写进 `pluginDependencies`。

### 单文件模板（兼容旧版）

顶层 `.ts` 无需 `package.json`，元数据写在类上，**最后加载**：

```ts title="plugins/example.ts"
import { Plugin } from "@fuyu-tdbot/plugin-api";
import type { Client } from "tdl";

export default class LifePlugin extends Plugin {
  type = "general"; // 插件类型可选 "general" 或 "bot" , "user"
  name = "插件唯一名称"; // 插件唯一名称
  version = "1.0.0"; // 插件版本号
  description = "插件简短描述"; // 插件简短描述
  constructor(client: Client) {
    super(client);
    this.cmdHandlers = {
      hello: {
        description: "问候用户",
        scope: "private",
        permission: "owner",
        showInHelp: true,
        handler: async (updateNewMessage, _args) => {
          console.log(updateNewMessage);
        },
      },
    };
  }
}
```

从单文件 / 旧类字段迁到包插件，见[插件迁移指南](/docs/plugin/Migration)。
